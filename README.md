# Banco INF101 - Etapa 1

Sistema simples de Registro e Gestão de Contas Bancárias desenvolvido em C++.

Este projeto corresponde à **Etapa 1** do trabalho proposto na disciplina de programação.

---

## Objetivo

O objetivo do programa é desenvolver um sistema básico para cadastro e gerenciamento de uma conta bancária, utilizando os fundamentos da linguagem C++.

Nesta primeira etapa são utilizados:

- Variáveis individuais;
- Tipos `int`, `string`, `double` e `bool`;
- Estrutura `switch`;
- Estruturas de repetição;
- Estruturas condicionais;
- Validação de entradas;
- Funções;
- Menu interativo no terminal.

---

## Funcionalidades

O sistema apresenta o seguinte menu:

```text
========== MENU ==========
